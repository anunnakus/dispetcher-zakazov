# Диспетчер заказов

Локальная программа для менеджера интернет-магазина. Сама забирает заказы из 1С и создаёт клиентские сообщения в 1С, чтобы их отправила уже настроенная там учётная запись SMS или почты. На рабочем Windows ничего не устанавливается и права администратора не нужны.

## Как запустить на офисном компьютере

1. Скачайте этот репозиторий архивом: Code → Download ZIP.
2. Распакуйте в «Документы» или на рабочий стол. Не в Program Files.
3. Дважды щёлкните `Запуск.bat`.
4. При первом запуске нужен интернет: в папку `runtime` скачается портативный Python. Права администратора не используются.
5. Не закрывайте чёрное окно, пока работаете. Страница откроется в браузере.

Если Windows спросит разрешение брандмауэра, его можно не давать. Программа слушает только этот компьютер.

Подробное управление заказами, шаблонами, SMS, почтой и Telegram — в файле `КАК-УПРАВЛЯТЬ.txt` и на вкладке «Как управлять» внутри программы.

Заказы и ключи отправки хранятся в папке `data` на этом компьютере и в GitHub не попадают.
